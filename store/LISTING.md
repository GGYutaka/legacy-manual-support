# Chrome ウェブストア 登録内容

ストアの開発者ダッシュボードに入力する内容の控えです。

## パッケージ

Releases の `legacy-manual-support-store.zip` (manifest.json が ZIP の直下にあるもの) をアップロードします。

## ストアの掲載情報

- **名前**: レガシー整備書サポート (manifest.json から自動)
- **概要** (132文字以内, manifest.json の description から自動):
  非公式。FAINESの古い整備書 (IE専用の閲覧画面・別PDFへリンクするPDF) をChromeで閲覧できるようにします。
- **カテゴリ**: 仕事効率化 → ツール
- **言語**: 日本語

### 説明

```
FAINES (整備情報提供システム) の古い整備書のうち、Internet Explorer 専用に作られた閲覧画面や、
別の PDF へリンクする PDF を、Chrome でそのまま閲覧できるようにする非公式の拡張機能です。

■ できること
・IE 専用の閲覧画面 (目次・本文・配線図のフレーム画面など) を Chrome で表示します。
  資料ごとに IE 専用の機能が必要かを自動で判定するので、設定は不要です。
・PDF を専用ビューアで開き、しおりやリンクから別の PDF (章ごとの PDF など) へ移動できるようにします。
  Chrome 標準の PDF 表示ではこの移動ができません。
・Chrome でそのまま開ける新しい資料には影響しません。

■ 使い方
インストール後、いつもどおり FAINES にログインして資料を開くだけです。
拡張機能のメニューで、IE 互換と PDF ビューアをそれぞれオン/オフできます。

■ ご注意
・本拡張機能は非公式のツールで、JASPA・FAINES・各自動車メーカーとは関係ありません。
  本拡張機能について、これらの団体・企業に問い合わせないでください。
・FAINES の会員として、FAINES の利用規約に従ってご利用ください。資料の保存・複製を行う機能はありません。
・VBScript や専用プラグイン (CAD ビューア等) が必要な画面には対応できません。

■ ソースコード・利用規約・不具合の報告
https://github.com/GGYutaka/legacy-manual-support
```

### 画像

- アイコン 128×128: `extension/icons/128.png`
- スクリーンショット 1280×800 (1〜5枚): 資料の本文が写らないものにする (FAINES・メーカーの著作物のため)。

## プライバシーへの取り組み (Privacy practices)

### 単一用途の説明 (Single purpose)

```
FAINES (faines.jaspa.or.jp) の古い整備書を Chrome で閲覧できるようにすることだけを目的としています。
IE 専用の閲覧画面を動かすための互換処理と、別の PDF へのリンクを辿れる PDF ビューアを提供します。
```

### 権限が必要な理由

| 権限 | 理由 |
|---|---|
| storage | 拡張機能メニューの設定 (IE 互換・PDF ビューアのオン/オフ) を保存するため。 |
| scripting | IE 専用の閲覧画面を Chrome で動かす互換スクリプトを、faines.jaspa.or.jp のページに登録するため。また、メニューの「IEモード記録をリセット」で、開いている FAINES のページの判定結果を消去するため。 |
| declarativeNetRequest | faines.jaspa.or.jp の PDF を開いたときに、拡張機能内の PDF ビューアで開くよう転送するため。 |
| ホスト権限 (https://faines.jaspa.or.jp/*) | 上記の互換処理と PDF ビューアを FAINES のページだけで動かすため。他のサイトでは動作しません。 |
| リモートコード | 使用していません。すべてのコード (pdf.js を含む) はパッケージに含まれています。 |

### データの使用

- 収集するデータ: **なし** (どの項目にもチェックを入れない)
- 3つの同意項目 (第三者に販売しない／単一用途と無関係な目的に使わない／信用力の判断に使わない) にチェック
- プライバシーポリシーの URL:
  https://github.com/GGYutaka/legacy-manual-support/blob/main/PRIVACY.md
